## 🚀 Dự án Trọng tâm: [DBI - Data Bridge Industrial](https://dbivn.com/)

<div align="center">
  <p><b>Giải pháp Gateway Công nghiệp (IIoT) & Cầu nối dữ liệu OT/IT toàn diện</b></p>
  <a href="https://dbivn.com/">
    <img src="https://img.shields.io/badge/Khám_phá_ngay-dbivn.com-blue?style=flat-square&logo=internet-explorer&logoColor=white" alt="DBI Portal"/>

**DBI** là hệ sinh thái phần mềm mã nguồn mở & giải pháp Gateway công nghiệp do tôi phát triển nhằm chuẩn hóa kết nối từ tầng thiết bị nhà xưởng (OT) lên hệ thống quản lý, giám sát và đám mây (IT/Cloud):

- 🔌 **Đa giao thức kết nối thiết bị:** Hỗ trợ trực tiếp Siemens S7 (S7-1200/1500), Mitsubishi (FX/Q Series qua McProtocol), Omron (FINS), Delta, Modbus RTU/TCP, OPC UA.
- ⚡ **DBI Core Ecosystem:**
  - **DBI.Runtime & DBI.Hive:** Nhân runtime hiệu năng cao và trung tâm điều phối dữ liệu tập trung.
  - **DBI.Drivers & DBI.DataRelay:** Hệ thống driver truyền thông đa thiết bị và chuyển tiếp dữ liệu thời gian thực.
  - **DBI.SoftPLC:** Chạy logic điều khiển trực tiếp trên môi trường máy tính công nghiệp (IPC).
  - **DBI.VisionKit:** Tích hợp thị giác máy tính công nghiệp (Machine Vision).
  - **DBI.CommTest & Server Releases:** Bộ công cụ kiểm thử đường truyền và đóng gói sản phẩm hoàn chỉnh.
